# 木作公式库（Joinery）

基本：`=E/300 * rate`（E = 宽度 mm，每尺 300mm）。
非全高的面板：再乘 `G/3000`。

| 类型 | Rate（RM/ft） | 公式 |
|---|---|---|
| 全高高柜 / 神台 / 电视墙 | 1350 | `=E/300*1350` |
| 衣柜 | 1250 | `=E/300*1250` |
| Feature / 床头板 | 1150 | `=E/300*1150*G/3000` |
| 暗门墙板 | 1100 | `=E/300*1100` |
| V-groove 墙板 | 1000 | `=E/300*1000*G/3000` |
| 下柜 | 750 | `=E/300*750` |
| 吊柜 / 中岛 | 650 | `=E/300*650` |
| Laundry 下柜 | 600 | `=E/300*600` |
| 书桌 / 梳妆台 | 450 | `=E/300*450` |
| 镜柜 | 450 | `=E/300*450` |
| 浴室柜 Vanity | 800 | `=E/300*800` |
| Powder vanity（按面积） | 175 / sqft | `=CEILING(E/300,0.5)*CEILING(G/300,0.5)*175` |

## 规则
- 尺寸从平面图（FLP）和立面量，写在 E/F/G，不要只写 L/S。
- 楼梯墙板：按展开面积，例如 `=2978/300*1000*6000/3000`。
- 暗门墙板如果包含一扇门，不要再在 Doors 另报实木门（Hana 疑似重复）。
- 每个项目加一行 ⭐ PS cabinetry accessories（默认 RM5,000）。
- 木作有 LED 灯带 → Electrical 要有 joinery LED point（每处 RM160）。
